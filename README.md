# Distance-Conversion of units

## Description
This program converts the distance from kilometer to miles

## How to run
1. Open the program in VS Code, Replit, or Google Colab
2. Run the program
3. Enter the distance in kilometers
4. Check the distance in miles

## Input Needed
- yes
- no
- distance in kilometers

## Sample Output
Enter : Yes
Enter distance in kilometer : 5 kilometers
The distance in miles is 3.10 miles
